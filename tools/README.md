# Vendor flashing tools

Download the Windows tools from the links provided by [Radxa's official instructions](https://docs.radxa.com/en/rock4/rock4d/low-level-dev/tool_rkdevtool):

- [Rockchip DriverAssitant](https://dl.radxa.com/tools/windows/DriverAssitant.zip)
- [Rockchip RKDevTool](https://dl.radxa.com/tools/windows/RKDevTool_Release.zip)

These downloads are hosted by Radxa and remain subject to their vendor terms, not Kinatric's GPL or CERN hardware license. Use the instructions for your actual board and image; the linked guide demonstrates a Radxa board.

The vendor URLs are not version-pinned and are not asserted to match the previously bundled DriverAssitant v5.13 and RKDevTool v3.30. Confirm compatibility with the target hardware before flashing. The archives have been removed from the current tree and maintained branch history. Obtain the tools directly from the vendor-hosted links above.
